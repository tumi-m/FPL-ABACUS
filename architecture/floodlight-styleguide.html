FLOODLIGHT

Midnight navy under two floodlight banks. One electric accent. Chrome bevels, a gloss pass, and everything angular cut at nine degrees. The FIFA 10 front end, translated for reading data off.

the one discipline

The skew, gloss and bevel apply to chrome. Never to data.

A chart mark, a table value and a player name are drawn flat and upright. The game-menu language wraps the interface; the numbers stay sober.

the 9° skew

Chrome cuts at −9°, text stays upright

fixture celllive now blank GWBPS +3 DEF 12 LIVE 67'

Never skew: cards, tables, table cells, charts, body copy, input fields, anything with a text cursor. Under 640px the skew softens to −6°.

Paste this into globals.css

The canonical token block lives in architecture/GAFFER_STYLE_GUIDE.md §3 — dark on bare :root, light overrides in both scopes so the toggle wins either way. This page renders exactly those values.

:root{
  --bg-base:#010C1F; --bg-sunk:#000513; --bg-raised:#061A31; --bg-overlay:#0E2945;
  --line:#1E3957; --line-hi:#36597D;
  --ink-hi:#EFF8FF; --ink-mid:#B4CBDF; --ink-lo:#87A2BB;
  --volt:#0AD0FF; --ice:#9DF0FF; --surge:#2CF2B6; --flare:#FF525B;
  --ultra:#A97AFF; --amber:#FFC035; --magenta:#F86CCA; --on-accent:#04121F;
  --heat-1:#4A3191 … --heat-6:#5EF8B1;   /* blue-forward sequential */
  --gloss / --bevel / --lift / --glow;    /* chrome recipes          */
  --skew:-9deg;                           /* −6deg under 640px       */
  --f-d:"Saira"; --f-u:"Barlow";
}
